# Swiggy Traffic & Conversion Analysis | Tableau

## Project Overview
Analyzed Swiggy traffic and conversion data using Tableau to understand user behaviour, traffic sources, device preferences, and conversion trends.

## Tools & Technologies
- Tableau Public
- Data Visualization
- Data Analysis

## Analysis Performed
- KPI Analysis
- Traffic Source Analysis
- Device Type Analysis
- Operating System Analysis
- Landing Page Analysis
- New vs Returning Users
- Session Trend Analysis
- Conversion Analysis
- Browser Analysis
- Geographic Analysis

## Key Objectives
- Understand traffic source performance.
- Analyze user behaviour across different devices.
- Compare new and returning visitors.
- Identify conversion trends.
- Explore geographic traffic distribution.
